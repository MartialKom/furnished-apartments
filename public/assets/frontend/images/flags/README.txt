Language Flags Directory
========================

This directory should contain flag images for the language switcher:
- en.png (English flag - 20x20 pixels recommended)
- fr.png (French flag - 20x20 pixels recommended)

You can download flag icons from:
- https://flagicons.lipis.dev/
- https://www.flaticon.com/
- Or use any other flag icon resource

The images should be optimized for web use (PNG format, small file size).
